Dos palabras que verás mucho

Área
El tema del que se ocupa un recurso: empleo, vivienda, salud, formación…
Colectivo
El grupo de personas al que se dirige: infancia, mayores, mujeres, migrantes…

Consejos

  • Prueba con una sola palabra: es más probable que coincida.
  • Combina Área y Colectivo para afinar, por ejemplo «Empleo» y «Juventud».
  • Puedes moverte por toda la web con el teclado: Tab para avanzar, Intro para abrir.
